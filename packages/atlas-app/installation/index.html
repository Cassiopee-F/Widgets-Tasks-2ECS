Atlas

L’application de terrain

Elle ouvre vos scènes Atlas depuis votre compte Grist, sur le terrain comme au bureau. Android uniquement.

Télécharger l’application

Version de test, non signée pour distribution.

  1. Ouvrez le fichier téléchargé.
  2. Android demandera d’autoriser l’installation depuis cette source — acceptez.
  3. Au premier lancement : l’adresse de votre instance Grist et votre clé API.

La clé se copie depuis votre profil Grist, rubrique « Clé API ». Elle reste sur le téléphone et n’est envoyée qu’à votre instance.
